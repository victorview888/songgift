# SongGift 定价策略与竞品调研

调研日期：2026-11-11。以下价格来自官方公开页面，币种为 USD；实际成交价格可能因地区、税费和活动变化。未创建竞品付费订单。

## 结论与本次边界

建议当前继续以 **$9.99 单首购买**为主。SongGift 面向生日、周年、婚礼等送礼场景；“免费预览和编辑歌词，再付款生成歌曲并下载”容易理解，适合先验证首单转化和交付质量。这个适配判断尚需真实用户数据验证，不代表已证明最优价格。

有复购证据后，可测试可选的 **3 首 $24.99** 歌曲包，保留单首入口。该价格比三次 $9.99 约优惠 16.6%，仅为内部待验证假设。现阶段不建议开发通用积分或按月订阅。

**本次未更改公开价格、订单报价、支付配置或权益模型；没有上线歌曲包。** 公开价格仍由服务端 `publicSongPriceUsd()` 读取配置，当前生产公开价为 $9.99。Owner 账号的 $1 测试报价不是公开价格，不得出现在定价页面、广告、结构化数据或搜索摘要中。

## 单次、歌曲包与积分/订阅

| 方案 | 当前适配度 | 用户与实现取舍 |
| --- | --- | --- |
| 单次 $9.99 | 优先保留 | 购买对象明确、首次决策简单，沿用现有每单支付与交付流程；复购仍需再次支付 |
| 可选 3 首包 | 待验证 | 可提高客单价并满足多个送礼对象，但首次付款更高；需要管理未用权益、退款与失败恢复 |
| 通用积分 | 暂缓 | 有利于多种生成操作按量计费，但增加单位换算和余额负担；需账本、幂等扣减、并发控制及支付对账 |
| 月订阅 | 暂缓 | 需要持续使用价值和足够高的消费频率；当前低频送礼假设尚不支持 recurring billing、续费与取消的额外工作 |

歌曲包即使不叫“积分”，后端仍需要可靠权益账本。上线前必须明确一次权益对应的交付物、扣减时点、失败返还、重试是否重复扣减、退款和未用权益处理；不能仅增加价格卡。

## 成本与价格实验

按支付通道、生成模型和订单分别记录成本，先排除 Owner 测试订单与内部流量。计算口径：

> 每单贡献 = 不含税收入 − 支付手续费 − 歌词及音乐生成/重试成本 − 分摊的未成交免费歌词成本 − 存储及下载成本 − 客服成本 − 退款与拒付损失准备 − 获客成本。

存储成本应包含长期保存的合理准备；获客前贡献与获客后贡献分开报告。当前没有真实费率、平均重试次数、退款率或获客成本数据，不能断言现价或套餐一定盈利。

例如，若内部暂定获客前贡献率目标为 70%，在不含税收入 $9.99 下，其他可变成本预算约为 $3。这只是决策假设，不是行业标准或本项目已实现利润。

先完善已获授权的音频样例、交付稳定性和异常处理，再考虑 $9.99 与 $14.99 单首价格实验，或面向复购用户测试 3 首包。每次只验证一个主要变化，提前写明样本范围、实验窗口与停止条件；报价在订单创建时锁定，不能改变已建立订单的金额。尚未选定实验或更改任何实际报价。

## 可执行观测指标

| 指标 | 口径与用途 |
| --- | --- |
| 首单转化 | 同一流量来源的新客首次付款人数 / 符合条件的新访客人数；同时拆分创建故事、生成歌词、开始支付、支付完成环节，避免把支付地区限制误判为价格问题 |
| 获客后每访客贡献 | 该访问批次带来的净收入减支付、生成、交付、退款准备及获客支出，再除以符合条件的访客数；用于判断提价后转化下降是否被利润改善覆盖 |
| 30/60/90 天复购率 | 已完成首单且具有相应完整观察窗口的用户中，再次付费的比例；按首购月份和渠道分组，不能把未满观察期的新用户算作未复购 |
| 重试、失败与交付 | 每笔付费订单平均外部生成调用次数、发生重试的订单占比、最终交付失败占比；区分免费歌词尝试、失败恢复和新购买，避免重复计费或低估生成成本 |
| 退款与客服成本 | 按原始订单批次统计退款/拒付净损失、原因与平均处理时间；用完整观察窗口复核套餐折扣是否覆盖额外支持成本 |

先从现有订单、支付和任务记录建立基线；访问和获客指标若尚无可靠采集，标注缺失，不用订单数代替访问量，也不为定价分析默认新增跟踪脚本。样本不足时保留现价。是否测试套餐、涨价的门槛由实际成本与样本量决定；任何预设比例都应标注为内部假设。

## 与 SEO 的衔接

- 主要内容围绕 `personalized song gift`、`custom birthday song`、`anniversary song gift` 等送礼需求，解释实际生成流程和交付物。
- 定价正文与 JSON-LD Offer 必须使用同一公开价格来源；避免把尚未上线的 $24.99 歌曲包或测试价格写进可索引内容。
- 免费歌词预览、付款后生成音频、下载方式及保存说明应与实际产品一致；不照抄竞品的免费音频试听、无条件退款或订阅权益。
- 竞争对手价格用于内部决策。若以后发布公开比较页，需要再次核实、标注日期和包含项差异，不承诺排名或未经证明的质量优势。
