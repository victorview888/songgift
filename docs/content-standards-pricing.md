# 内容规范、举报机制与公开价格（2026-11-10）

本轮按用户列出的三项问题调整，从生产 master / 21d05b2 独立开发，未合入 Waffo。
参考：https://docs.waffo.ai/mor/account-reviews/aup 。模板要求实际审核与可工作的举报渠道，
不是仅发布文字。本轮沿用 SongGift 已有 DeepSeek、Supabase 和 Owner 鉴权。

## 公开内容

- /policies/content-standards：逐类禁止色情/NSFW、暴力血腥和恐怖活动、仇恨歧视、
  儿童不安全内容/CSAM、深度伪造/冒充、版权商标侵权；说明适用范围、自动与人工审核、
  举报、处理目标和申诉。服务条款链接该规范。
- /report：无需账号，提交类别、引用、20–4000 字描述及可选联系邮箱。不接收附件，
  不要求复制/转发非法材料。数据库提交成功后才显示随机编号；失败保留输入和原请求号。
- /pricing 与首页：标准价格从 SONG_PRICE_USD 读取，与普通订单报价共用函数；当前
  US$9.99/首、USD、PayPal、单次购买。明确免费文字预览/生成前手动改词、一次音乐生成
  和下载；额外编曲、歌曲或偏好性重做需另行报价与同意。旧报价和账号特定优惠不改写。
- 页脚、帮助导航、创作/歌词/歌曲/联系页提供定价、规范和举报入口。

## 自动检查及限制

src/lib/safety/moderation.ts 使用已配置的 DeepSeek API，system 指令与不可信输入分开，
要求严格 JSON 结论，检查异常/超时/缺失或不一致结果均拒绝继续，不放行付费模型请求。

实际接入：故事写词前、生成歌词返回后、打开新的 PayPal 结账前、预留任务冻结快照后且
提交音乐模型前。最后一处检查冻结快照，避免检查期间编辑造成未审文字进入付费模型。
保存歌词仍可单独操作。已完成歌曲和已提交任务的查询/保存恢复不重提模型。

若付款后的冻结快照检查未通过或不可用，任务进入 needs_review，不自动改写快照、
放行、重提生成或退款，需 Owner 根据原订单和问题进行人工核查。没有新增原始音频
波形分类器，公开说明没有声称全量音频独立自动检测；音频依赖供应商机制及举报人工复核。

DeepSeek 在本来歌词处理之外会接收审核所需的故事/生成及手工编辑歌词；隐私政策已说明。
分类器误判可通过举报表单选择申诉，不承诺检测所有违规或保证 Waffo 账户审核通过。

## 举报存储和管理员流程

增量迁移：supabase/migrations/20261110123000_content_reports.sql。
新增 content_reports、content_report_limits、content_report_reviews，均启用 RLS；
匿名及普通账号没有读写表或调用 RPC 的权限。网站服务角色执行限定操作。

POST /api/content-reports 复用同源 JSON 检查；字段有长度及类别约束、隐藏诱捕字段，
采用带服务端密钥的 IP 哈希限频（每小时 5 个新举报），原始 IP 不进入限频表。
重复请求按随机 UUID 与正文哈希复用；限频与写入同一事务，失败不返回已收到。
旧限频窗口在后续提交时清理。外部链接仅作文字保存，不自动获取或下载内容。

/admin/reports提供 Owner 举报列表、每页 20 条、状态筛选，
展示可选联系邮箱（未经身份验证）和最近 5 条核查记录。每个 API 都实时验证 Owner，
写入 RPC 在事务内再验证 active/role；撤权、陈旧记录与请求内容变化被拒绝。
状态变更及操作者、记录和请求号原子保存，重复请求不重复追加核查记录。

Owner 要定期查看该队列，并优先核查儿童安全/恐怖活动/可信威胁。处理目标为：紧急
24 小时内开始，普通 3 个工作日内开始，7 个工作日内结论或进展，申诉 10 个工作日内
结论或进展；复杂情形说明原因，联系邮箱可用时人工通知。不声称全天候值班。

“已采取措施”只是对实际措施的登记，不自动删音频、封号、发送邮件或退款。Owner 应先
核实证据及订单归属，必要时通过现有数据库/存储和供应商管理工具撤下已确认违规的文件、
联系相关方或依法保全/上报，再记录处理依据和通知情况。举报不自动授权访问他人的歌曲。

邮箱 MX 未配置的问题仍需运营者处理；站内举报不依赖邮箱收信或 Resend 自动通知。
