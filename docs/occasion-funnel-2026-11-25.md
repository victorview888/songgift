# 场景统计、可读性和通知诊断

开发基线：生产 PR #27 的合并提交 `c7a2153`。本轮沿用现有第一方统计和后台权限，不增加收费服务。

## 用户界面

- 调深现有辅助文字和强调色，改善样曲标签、说明文字、浅绿背景及创建页摘要的小字对比度；照片和布局沿用现有版本。
- 播放统计在音频真正触发 `playing` 后记录。加载失败、单纯浏览播放器和同页重复播放不增加该播放器的播放事件；播放其他样曲仍会分别记录。
- 创建页首次非空编辑记录一次开始填写，开始新故事或清除账户状态后重置；不因恢复草稿自动记录。

## 后台来源与转化

`/admin/analytics` 增加生日、婚礼、纪念日、圣诞节等粗粒度场景与步骤的交叉统计，包含公开样曲播放、首次编辑、已有故事/歌词步骤、个人预览播放和进入付款。

- 继续默认关闭，只有允许统计且没有 DNT/GPC 的访客才采集。浏览器只发送固定枚举；未知场景为 NULL。不记录原始网址、查询参数、故事、歌词、姓名、邮箱或样曲音频地址。
- 个人预览播放经过现有已登录订单权限校验，场景从属于当前用户的数据库订单读取，忽略浏览器声称的其他场景。
- 历史事件不补猜场景，显示“未指定场景”。首次编辑的场景是当时表单选项；后续修改场景不会改写历史事件。
- 浏览器事件仍可能缺失或被伪造，不代表唯一用户、已收款或已交付，不据此与全站订单直接计算转化率。
- 独立显示所选期间创建的正式个人预览的**当前**状态（已就绪、处理中、已确认失败、需核查）。它是按创建日期划分的记录集合，不是当天完成数；公开样曲和测试环境排除。
- 继续沿用 30 天浏览器数据窗口、限额、事件键幂等及撤回删除。隐私文档与 sitemap 日期按本次真实变更更新。

## 系统状态与通知

`/admin/system` 展示通知发件箱的待处理、发送中、服务商已接受、失败、需核查、重试和跳过数量。只返回汇总，不返回邮箱、收件人姓名或订单链接。RPC 失败显示“查询失败”，不显示虚假的零条。

网站进程的有效通知配置与独立维护 Worker 分开说明。维护记录展示真实结果、开始/结束时间及最近 15 分钟内是否有完成记录；这些信息不推断 Worker 的当前启用设置。服务商已接受也不等于最终收件箱送达。

2026-11-25 发布前只读核查：生产维护表尚无开始/完成记录，通知发件箱为空，网站健康检查的歌曲通知凭据标志为 false。登录验证码走 Supabase SMTP，不能以验证码可用推断歌曲完成通知也可用。本轮不启用维护 Worker、不调用真实发信或生成接口。完成通知仍需独立配置与受控投递验证。

## 迁移、兼容与回退

CLI 生成的增量文件：`supabase/migrations/20261125131733_occasion_funnel_and_notification_diagnostics.sql`。完整 schema 同步该 SQL。

迁移增加可空场景列、事件枚举和一个私有通知汇总 RPC，扩展已有报表。新 11 参数写入 RPC 不设默认值；旧 10 参数签名与原默认值保留，转发到新实现，旧应用的 8/10 参数调用继续有效。所有相关函数使用 SECURITY INVOKER，仅 service_role 可执行；既有 RLS 和普通用户权限不变。

发布顺序为隔离迁移/回归与两种运行时验收，应用增量生产迁移，再合并触发 Cloudflare Git 部署，并以正式站健康接口的实际提交核对结果。回退应用到 `c7a2153` 即可停用新增前端行为，保留增量数据库列和兼容函数，不删除订单、音频、账本或统计数据。

## 验证方式

- `npm run test:growth`：权限、旧库升级、枚举验证、场景来源、幂等/限额/撤回、汇总与失败降级。
- `node --test --test-isolation=none tests/audio-preview.test.mjs tests/delivery-operations.test.mjs`：原有预览、付款解锁及通知行为回归，供应商均模拟。
- `npm run lint`、TypeScript 检查、Next webpack 与 vinext Cloudflare 构建。
- `node scripts/test-customer-runtime.mjs serve` 启动内存 PostgreSQL/Auth/Storage；在隔离 Next / workerd 中运行 `scripts/test-occasion-funnel-browser.mjs`。Next 使用 `http://localhost:3042`，workerd 使用 `http://127.0.0.1:3041`；通过 `SONGGIFT_FUNNEL_URL` 指定。验收失败音频不计播放、成功播放、重复播放、首次编辑、订单场景、Owner 后台及撤回，所有业务仅使用本机假数据。
- 两种运行时的 `scripts/test-seo-runtime.mjs` 检查公开/私有索引指令、canonical、结构化数据、sitemap 和更新日期。
- 7 个公开页面在 390/1440 像素进行 axe 检查和溢出检查。照片/渐变背景中工具无法确定的文字仍需人工观察，不将自动检查通过描述为全站无障碍认证。
